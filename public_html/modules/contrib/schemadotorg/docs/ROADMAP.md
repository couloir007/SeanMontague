# Schema.org Blueprints roadmap

## Public coordination

[#3279761](https://www.drupal.org/project/schemadotorg/issues/3279761) is the

## Ongoing maintenance

- Maintain supported core and contributed-module integrations.
- Address regressions and API documentation.
- Coordinate community-maintained issues.
- Improve Schema.org Blueprints Recipes support.
- Improve Schema.org Blueprints JavaScript test coverage.
- Improve settings form test coverage for sub-modules.
- Convert hooks to OOP hooks.
