# Custom Field

The **Custom Field** module delivers a powerful, performant way to create rich,
structured, multivalue fields — all stored efficiently in a **single database
table**.

## Features & Benefits

- **Superior Performance & Scalability**  
  Store multiple related values in one table row. This eliminates
  expensive table joins, reduces database bloat, and dramatically improves query
  performance.

- **True Structured Data**  
  Build complex, reusable data structures using multiple columns of different data types —
  all through the standard Field UI.

- **Enhanced Authoring Experience**  
  Choose between [Stacked](field-widgets/stacked.md) or responsive [Flexbox](field-widgets/flexbox.md) widgets. Logically group
  fields with collapsible sections and custom labels — often replacing the need for additional modules and/or custom code.

- **Full Subfield Control**  
  Each subfield has its own widget, label, and settings, with extensive
  widget/formatter support and advanced [integrations](integrations/index.md).

- **Reusability & Efficiency**  
  Clone field configurations from **any** entity type. Reduce configuration overhead and contrib module dependencies.

- **Developer Friendly**  
  Extensible plugin system for custom field [types](plugins/type/index.md), [widgets](plugins/widget/index.md), and [formatters](plugins/formatter/index.md).
  Granular subfield-level [translation support](field-configuration/multilingual.md).

**In short:** Custom Field is the modern, high-performance alternative when
Paragraphs or entity references feel too heavy.
