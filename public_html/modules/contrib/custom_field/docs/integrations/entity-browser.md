# Entity Browser integration
The **Custom Field - Entity Browser integration** module provides a custom [Entity browser widget](../plugins/widget/entity-reference-entity-browser.md)
for [entity reference](../plugins/type/entity-reference.md) subfields.

## Dependencies
- [Entity Browser](https://www.drupal.org/project/entity_browser){:target="_blank"} (`entity_browser`)
- Custom Field - Entity Browser (`custom_field_entity_browser`)
