# AI (Artificial Intelligence) integration
Integration with the [AI module](https://www.drupal.org/project/ai){target="_blank"}
via the **Custom Field AI** (`custom_field_ai`) submodule to provide AI-powered
features such as:

- AI translation
- AI automators
- Field Widget Actions

## Dependencies
- AI Custom Field (`custom_field_ai`)
- [AI (Artificial Intelligence)](https://www.drupal.org/project/ai){:target="_blank"} (`ai`)
