# Single Directory Components
The Custom Field SDC display module integrates fields and view modes with
Single Directory Components. This module provides advanced settings in the manage display page to
select one or more fields of **ANY** type to fill slots in a Single Directory
Component. This module is a simple alternative to the [Single Directory Components: Display](https://www.drupal.org/project/sdc_display){target="_blank"} module.

## SDC (Single Directory Component) field formatter
The [SDC (Single directory component)](../field-formatters/sdc.md)
formatter can be applied to any custom field as a simple yet powerful way to
display a single directory component.

## Dependencies
- (optional) Custom Field - SDC display (`custom_field_sdc`)
