# Linkit integration
The **Custom Field Linkit integration** module provides a [Linkit](https://www.drupal.org/project/linkit){target="_blank"}
widget and formatter for subfields of type [uri](../plugins/type/uri.md) and 
[link](../plugins/type/link.md).

## Dependencies
- [Linkit](https://www.drupal.org/project/linkit){target="_blank"} (`linkit`)
- Custom field - Linkit integration (`custom_field_linkit`)

## Configuration

1. Enable the `custom_field_linkit` module.
2. Add a subfield of type [uri](../plugins/type/uri.md) or [link](../plugins/type/link.md).
3. Select the **Linkit** widget for the subfield in the manage form display page.
4. (optional) Select the **Linkit** formatter for the subfield in the manage display page.
