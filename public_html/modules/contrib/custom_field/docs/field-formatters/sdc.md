# SDC (Single directory component) formatter
The **SDC** (`custom_field_sdc`) formatter provides the most simplistic yet powerful way to incorporate
**Single Directory Components** with the ability to assign a subfield with
full formatting capabilities to a particular slot.

| Setting   | Label     | Description                                          | Default |
|-----------|-----------|------------------------------------------------------|---------|
| component | Component | The **Single Directory Component** to use            |         |
| slots     | Slots     | The slot options provided for the selected component |         |
| props     | Props     | The prop options provided for the selected component |         |

> [!warning] Component options
> The available **Single Directory Component** options are provided by your
> theme or custom module and therefore are required for this formatter to work.
