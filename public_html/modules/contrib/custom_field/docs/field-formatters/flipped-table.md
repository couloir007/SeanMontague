# Table (flipped) formatter
The **Table (flipped)** (`flipped_table`) formatter displays the custom field items as HTML table with the rows and columns flipped.
This formatter is particularly useful for multi-value fields for comparison.

## Settings
| Setting     | Label                        | Description                                                     | Default |
|-------------|------------------------------|-----------------------------------------------------------------|---------|
| hide_empty  | Hide rows with empty columns | Option to skip rendering a row when all column values are empty | FALSE   |
