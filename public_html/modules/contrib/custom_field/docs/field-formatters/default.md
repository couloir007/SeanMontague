# Default formatter
The **Default** (`custom_formatter`) renders the items using a theme hook implementation.

> [!tip] Advanced theming
> While rarely necessary, advanced theming can be achieved by copying the
> following templates to your theme and modifying them as needed:
>
- `custom_field/templates/custom-field.html.twig`
- `custom_field/templates/custom-field-item.html.twig`
