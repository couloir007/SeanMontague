# Inline formatter
The **Inline** (`custom_inline`) formatter renders the items inline using a
simple separator and no additional wrapper markup.

## Settings

| Setting         | Label           | Description                                                                              | Default |
|-----------------|-----------------|------------------------------------------------------------------------------------------|---------|
| show_labels     | Show labels?    | Option to display labels along with the value                                            | FALSE   |
| label_separator | Label separator | Text to display between value and label for each item when `show_labels` is `#!php TRUE` | :       |
| item_separator  | Item separator  | Text to display between each item                                                        | ,       |
