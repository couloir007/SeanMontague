# Entity reference radios widget
The **Radios** (`entity_reference_radios`) widget provides a list of 
entity label options using the `<input type="radio">` form element.

## Settings
| Setting      | Label        | Description                                                  | Default |
|--------------|--------------|--------------------------------------------------------------|:--------|
| empty_option | Empty option | The default option to display when the field is not required | N/A     |

## Field types
- [entity_reference](../type/entity-reference.md)
