# Linkit URL widget
The **Linkit** (`linkit_url`) widget provides an autocomplete interface for 
internal and external linking. [Linkit](https://www.drupal.org/project/linkit){target="_blank"}
supports linking to all types of entities that define a canonical link template.

## Settings
| Setting        | Label          | Description                               | Default |
|----------------|----------------|-------------------------------------------|:--------|
| placeholder    | Placeholder    | Text shown inside the field when empty    |         |
| linkit_profile | Linkit profile | The Linkit profile to use for this widget | default |

## Dependencies
- Custom Field - Linkit integration[`custom_field_linkit`] sub-module
- [Linkit](https://www.drupal.org/project/linkit){target="_blank"}
