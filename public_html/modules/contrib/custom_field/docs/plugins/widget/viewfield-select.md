# Viewfield select widget
The **Viewfield select** (`viewfield_select`) widget is used to select a view as a reference along with
its display. Arguments to pass to the view and the number of items to display are
additional inputs.

## Settings
| Setting      | Label        | Description                               | Default  |
|--------------|--------------|-------------------------------------------|----------|
| empty_option | Empty option | Option to show when field is not required | - None - |
