# Date and time (local) widget
The **Date and time (local)** (`datetime_local`) widget provides the `<input type="datetime-local">`
form element which specifies a date and time input field. An optional time zone
field can be specified via configuration.

## Settings
| Setting    | Label      | Description                                 | Default   |
|------------|------------|---------------------------------------------|-----------|
| year_range | Year range | Sets min/max attributes for start date year | 1900:2050 |

## Field types
- [datetime](../type/datetime.md)
