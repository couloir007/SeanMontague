# Media library widget
The **Media library** (`media_library_widget`) widget provides the ability to
attach media entities to entity reference subfields. This widget is only
available for entity reference subfields that are of type `media`.

## Settings
| Setting     | Label     | Description                                                    |
|-------------|-----------|----------------------------------------------------------------|
| media_types | Tab order | Controls the tab order of available media bundles in the modal |

## Field types
 - [entity_reference](../type/entity-reference.md)

## Dependencies
- Media Library (`media_library`)
- Custom Field - Media (`custom_field_media`)
