# Integer widget
The **Integer** (`integer`) widget provides the `<input type="number">` form
element to enter an integer value.

## Settings
| Setting     | Label       | Description                                                       | Default |
|-------------|-------------|-------------------------------------------------------------------|:--------|
| placeholder | Placeholder | Text that will be shown inside the field until a value is entered |         |
