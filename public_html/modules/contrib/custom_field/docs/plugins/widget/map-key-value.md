# Map: Key/Value widget
The **Map: Key/Value** (`map_key_value`) widget allows entering unlimited key/value pairs.

## Settings
| Label       | Setting     | Description                             | Default |
|-------------|-------------|-----------------------------------------|---------|
| Key label   | key_label   | The table header label for key column   | Key     |
| Value label | value_label | The table header label for value column | Value   |
