# File widget
The **File** (`file_generic`) widget provides the `<input type="file">` 
form element which defines a file-select field and a "Browse" button for file 
uploads.

## Settings
| Setting            | Label              | Description                         | Default  |
|--------------------|--------------------|-------------------------------------|:---------|
| progress_indicator | Progress indicator | Indicator to show file is uploading | throbber |
