# Radios widget
The **Radios** (radios) widget provides the HTML `<input type="radio">` form 
element, allowing users to select exactly one option from a set of predefined
choices.

> [!Note]
> This widget depends on `allowed_values` field setting with options set.

## Settings
| Setting      | Label        | Description                                             | Default |
|--------------|--------------|---------------------------------------------------------|:--------|
| empty_option | Empty option | The option label to show when the field is not required | N/A     |

## Field types
- [float](../type/float.md)
- [integer](../type/integer.md)
- [string](../type/string.md)
