# Select widget
The **Select** (`select`) widget provides a dropdown list of options for the
HTML `<select>` form element.

> [!Note]
> This widget depends on `allowed_values` field setting with options set.

## Settings
| Setting      | Label        | Description                                             | Default    |
|--------------|--------------|---------------------------------------------------------|:-----------|
| empty_option | Empty option | The option label to show when the field is not required | - Select - |


## Field types
- [float](../type/float.md)
- [integer](../type/integer.md)
- [string](../type/string.md)
