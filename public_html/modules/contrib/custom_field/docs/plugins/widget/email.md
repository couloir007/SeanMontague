# Email widget
The **Email** (`email`) widget provides the `<input type="email">` form element to enter 
email addresses.

## Settings
| Setting     | Label             | Description                                                       | Default |
|-------------|-------------------|-------------------------------------------------------------------|:--------|
| size        | Size of textfield | The visible width of the input element defined by character count | 60      |
| placeholder | Placeholder       | Text to display in the textfield when empty                       |         |

## Field types
- [email](../type/email.md)
- [string](../type/string.md)
