# Entity reference select widget
The **Select** (`entity_reference_select`) widget provides a drop-down list of
entity labels as a `<select>` form element.

## Settings
| Setting      | Label        | Description                                                  | Default    |
|--------------|--------------|--------------------------------------------------------------|:-----------|
| empty_option | Empty option | The default option to display when the field is not required | - Select - |

## Field types
- [entity_reference](../type/entity-reference.md)
