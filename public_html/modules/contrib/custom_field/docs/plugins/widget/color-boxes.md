# Color boxes widget
The **Color boxes** (`color_boxes`) widget is a simple color picker 
composed of clickable boxes depicting a predefined set of hexadecimal color
values.

## Settings
| Setting        | Label          | Description                                  |
|----------------|----------------|----------------------------------------------|
| default_colors | Default colors | A predefined set of hexadecimal color values |

## Field types
- [color](../type/color.md)
