# Viewfield formatter
The **Viewfield** (`viewfield_default`) formatter renders the output of a view based on it's
stored display name and optional arguments.

## Settings
| Label               | Setting             | Description                                                   | Default |
|---------------------|---------------------|---------------------------------------------------------------|---------|
| Always build output | always_build_output | Option to render output even if the view produces no results. | FALSE   |
