# Time range formatter
The **Time range** (`time_range_default`) formatter displays the start and end value in a user-defined time format
sortable by time settings. A separator can be set to separate each time value.

## Settings

| Setting                | Label          | Description                          | Default         |
|------------------------|----------------|--------------------------------------|-----------------|
| separator              | Time separator | Separator between start and end time | -               |
