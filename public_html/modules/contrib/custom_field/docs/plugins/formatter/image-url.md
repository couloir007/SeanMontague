# URL to image formatter
The **URL to image** (`image_url`) formatter displays the URL to the original image or
an image style if one is specified.

## Settings
| Label                   | Setting                 | Description                                                           |
|-------------------------|-------------------------|-----------------------------------------------------------------------|
| Image style             | image_style             | An optional image style to apply                                      |
