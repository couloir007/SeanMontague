# Label formatter
The **Label** (`entity_reference_label`) formatter is used to render the label of the 
referenced entity either as plain text or a link to the entity's page.

## Settings
| Setting | Label                               | Default |
|---------|-------------------------------------|---------|
| link    | Link label to the referenced entity | FALSE   |
