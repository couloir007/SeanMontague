# Link text formatter
The **Link text** (`link_text`) formatter provides the ability to display only link text when
available. The value will not be displayed if the link text is empty.

> [!tip]Typical use case
> This formatter is particularly useful for splitting out the link text and URL
> for use in the [SDC (Single directory component) formatter](../../field-formatters/sdc.md)
> as different slot values.
