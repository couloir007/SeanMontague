# Duration formatter
The **Duration** (`duration`) formatter is used to display a calculated 
duration as granular parts of time with optional separator between them.

## Settings

| Setting              | Label       | Description                       | Default            |
|----------------------|-------------|-----------------------------------|--------------------|
| duration_granularity | Granularity | Granularity of the output         | days:hours:minutes |
| duration_separator   | Separator   | String to separate duration parts | ,                  |
