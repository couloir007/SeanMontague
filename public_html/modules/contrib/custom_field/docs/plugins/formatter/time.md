# Time formatter
The **Time** (`time`) formatter displays the value in a user-defined time
format. See the [PHP manual](https://www.php.net/manual/en/datetime.format.php#refsect1-datetime.format-parameters){target="_blank"} for available options.

## Settings
| Setting     | Label       | Description                 | Default |
|:------------|-------------|-----------------------------|---------|
| time_format | Time format | A user-defined time format. | h:i a   |
