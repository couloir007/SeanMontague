# Map inline formatter
The **Map inline** (`map_inline`) formatter renders the values inline using a simple separator
and no additional wrapper markup.

## Settings

| Setting        | Label          | Description                            | Default |
|----------------|----------------|----------------------------------------|---------|
| item_separator | Item separator | A textual string to separate each item | ,       |
