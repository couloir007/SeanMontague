# Rendered entity
The **Rendered entity** (`entity_reference_entity_view`) formatter is used to render the referenced 
entity in a particular view mode.

## Settings
| Setting   | Label     | Description                         | Default |
|-----------|-----------|-------------------------------------|---------|
| view_mode | View mode | The view mode to render the entity. | default |
