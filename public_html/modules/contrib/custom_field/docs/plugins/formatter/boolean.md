# Boolean formatter
The **Boolean** (`boolean`) formatter displays values as preset options or as custom text.

## Settings

| Setting             | Label                   | Description                                                     | Default |
|---------------------|-------------------------|-----------------------------------------------------------------|---------|
| format              | Output format           |                                                                 | yes-no  |
| format_custom_true  | Custom output for TRUE  | Text to display for `custom` format when value is `#!php TRUE`  |         |
| format_custom_false | Custom output for FALSE | Text to display for `custom` format when value is `#!php FALSE` |         |
