# Datetime (custom) formatter
The **Custom** (`datetime_custom`) formatter displays the date and time in a custom 
format with additional time zone settings depending on the date type.

## Settings

--8<-- "formatter/date.md:formatter_settings_timezone"

### Additional settings

| Setting     | Label            | Description                    | Default      |
|-------------|------------------|--------------------------------|--------------|
| date_format | Date/time format | Format for displaying the date | Y-m-d\TH:i:s |
