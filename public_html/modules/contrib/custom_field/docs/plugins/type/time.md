# Time
The **Time** (`time`) custom field type plugin is used to store a time value.

## Field settings
| Setting         | Label                                 | Description | Default |
|-----------------|---------------------------------------|-------------|---------|
| seconds_enabled | Add seconds parameter to input widget |             | FALSE   |
| seconds_step    | Step to change seconds                |             | 5       |

## Widgets
| Label                            | Plugin ID   | Default |

| [Hidden](../widget/hidden.md)    | hidden      |         |
