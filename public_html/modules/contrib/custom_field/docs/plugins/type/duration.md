# Duration
The **Duration** (`duration`) custom field type plugin is used to store a calculated number of
seconds as an integer.

## Field Settings
| Setting          | Label            | Description                  | Default |
|------------------|------------------|------------------------------|---------|
| duration_options | Duration options | An array of duration options |         |

## Widgets
| Label                             | Plugin ID | Default |
|-----------------------------------|-----------|---------|

| [Hidden](../widget/hidden.md)     | hidden    |         |
